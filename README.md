# Login API

A professional Login API built using Python and Flask.

## Features

- User login authentication
- Email and password validation
- Proper error handling
- JSON responses
- HTTP status codes
- Professional folder structure

## API Endpoint

### Login

**Method:** POST

**URL:**
http://127.0.0.1:5000/login

## Request Body

```json
{
  "email": "admin@gmail.com",
  "password": "admin123"
}
